# 🧠 Grade 5 Math AI Assistant

هذا المساعد التعليمي مصمم خصيصاً لطلاب الصف الخامس الابتدائي. يعتمد التطبيق على أقوى نماذج الذكاء الاصطناعي (Large Language Models) لتقديم شروحات رياضية دقيقة ومبسطة.

## 🚀 لماذا هذا الإصدار أفضل؟
- **دقة عالية:** يستخدم موديل `Qwen2.5-72B` القوي في حل المسائل الرياضية.
- **دعم اللغة العربية:** يفهم ويجيب باللغتين العربية والإنجليزية بطلاقة.
- **استجابة فورية (Streaming):** تظهر الإجابة أمام الطالب حرفاً بحرف، مما يزيد من التفاعل.
- **خفيف جداً:** لا يحتاج لتحميل موديلات ضخمة داخل الـ Space، مما يضمن ثبات الخدمة.

## 🛠️ المتطلبات التقنية (Tech Stack)
- **Gradio:** للواجهة الرسومية.
- **Hugging Face Inference API:** للاتصال بالموديل السحابي.
- **Python 3.12:** لضمان التوافقية الكاملة.
